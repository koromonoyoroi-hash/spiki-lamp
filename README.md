================

パチンコ風の常駐型ゲームです。
分かる人に伝わる言い方をすると「確変付きのジャグラー」です。


■基本操作
・通常時		：4秒ごとに1回抽選が走ります。
・大当たり時	：「大当たりを消化」ボタンを押して大当たりを消化します。
・制限時間終了時：ゲーム結果が表示され、最終持ち玉などを確認できます。

■各種ボタンについて
・大当たりを消化ボタン：初当たり時や確変中に押せるようになります。
						メイン画面左上の現在の状態表示の画像や、左下のランプ画面をクリックしても大当たりを消化できます。
						PCの場合、Enter/Ctrl/Spaceキーでも大当たりを消化できます。

・途中終了ボタン	：ゲームを途中で終了し、結果を表示します。
					　大当たり待機中は、先に大当たりを消化してください。

・設定ボタン：各種設定ができます。
ユーザ名				・・・ランキングに載る名前を変更できます（ランキングは未実装）
ランプ音量				・・・ランプ音の音量を調整できます
ランプ音確認			・・・ランプ音の音量確認ができます
ランプ以外の音量		・・・ランプ音以外の音の音量を調整できます
ランプ以外音確認		・・・ランプ音以外の音の音量確認ができます
Readmeを開く			・・・このテキストが開けます
遊戯中スペック詳細確認	・・・現在選択しているスペックの詳細を確認出来ます

■ランプ画面
通常時に大当たりを引くとランプが光ります。
光ったら「大当たりを消化」ボタンを押してください。
確変中はランプが大当たり前の状態になります。
ランプの下には現在の回転数が表示されます。

■結果について
制限時間が終了すると、ゲーム結果が表示されます。
結果はcsvで保存したり、Twitter（現X)で共有できます。
再度プレイする際は「スペック選択」ボタンを押してください。

■動作環境
PCやスマートフォンのWebブラウザ

音声を使用するため、音量にご注意ください。

■画面サイズについて
スマホの縦画面横画面両方で使えるようにしています。
PCでもウィンドウの横幅を狭めるとスマホの縦画面のような配置になります。
