# ｽﾋﾟｷﾗﾝﾌﾟ【同人作品】　web版 ver0.1.1

パチンコ風の常駐型ゲームです。  
分かる人に伝わる言い方をすると「確変付きのジャグラー」です。

## 基本操作

- **通常時**：4秒ごとに1回抽選が走ります。
- **大当たり時**：「大当たりを消化」ボタンを押して大当たりを消化します。
- **制限時間終了時**：ゲーム結果が表示され、最終持ち玉などを確認できます。

## 各種ボタンについて

- **大当たりを消化**：初当たり時や確変中に押せるようになります。
- **途中終了**：ゲームを途中で終了し、結果を表示します。大当たり待機中は、先に大当たりを消化してください。
- **設定**：各種設定ができます。

設定項目：

- ユーザー名：ランキングに載る名前を変更できます。（ランキングは未実装）
- ランプ音量：ランプ音の音量を調整できます。
- ランプ音確認：ランプ音の音量確認ができます。
- ランプ以外の音量：ランプ音以外の音量を調整できます。
- ランプ以外音確認：ランプ音以外の音量確認ができます。
- Readmeを開く：このテキストを開きます。
- 遊戯中スペック詳細確認：現在遊戯中のスペック詳細を確認できます。

## ランプ画面

通常時に大当たりを引くとランプが光ります。  
光ったら「大当たりを消化」ボタンを押してください。

確変中はランプが大当たり前の状態になります。  
ランプの下には現在の回転数が表示されます。

## 結果について

制限時間が終了すると、ゲーム結果が表示されます。  
結果はCSVで保存したり、Twitter（現X）で共有できます。

再度プレイする際は「スペック選択」ボタンを押してください。

## 動作環境

PCやスマートフォンのWebブラウザ

音声を使用するため、音量にご注意ください。

## 画面サイズについて

スマホの縦画面・横画面の両方で使えるようにしています。  
PCでもウィンドウの横幅を狭めると、スマホの縦画面のような配置になります。
